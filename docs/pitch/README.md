# Architecture pitch deck

Marp slide source for CTO / technical leadership meetings.

## Generate PDF

From the API repo root:

```bash
npm run docs:pitch-pdf
```

Output: `docs/pitch/ARCHITECTURE-PITCH.pdf`

## Edit slides

Edit [`ARCHITECTURE-PITCH.md`](./ARCHITECTURE-PITCH.md) — Marp markdown with `---` slide separators.

## View in VS Code

Install the [Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode) extension for live preview.
